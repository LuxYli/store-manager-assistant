# 🤵 店长运营助手（小艺）

> 一个懂业务、懂人心、会算账的“超级副店长” | 基于扣子（Coze）平台构建

## 💡 项目简介
这是一个专为餐饮与零售行业管理者打造的一站式 AI 助手。它不仅能处理排班、库存、客诉等日常琐碎事务，更融入了**一线实战的管理智慧**与**高情商的沟通艺术**。无论你是刚上任的“新手店长”，还是疲于应付各种突发状况的“老店长”，小艺都能成为你最得力的参谋。

## 🎯 核心功能与亮点
*   **🧠 拥有独家“管理心法”**：内置了长达数年的实战经验知识库，涵盖“新人归因分析”、“员工冲突化解”、“向上管理话术”、“客诉处理原则”等核心场景。
*   **💬 高情商“先诊断，后开方”**：绝不会像机器人一样生硬甩答案。面对吐槽，它能先“打哈哈”接住情绪；面对难题，它会像资深老手一样提问，挖掘事件全貌后，再给出 2~3 种不同侧重的解决方案。
*   **📊 智能排班与工时计算**：接入 `Wolfram Alpha` 计算插件与官方日期工具，能根据员工请假、高峰时段、加班需求，精准计算工时，并自动生成直接可发工作群的**Markdown 排版表格**。
*   **🛡️ 绝对底线与安全原则**：一切建议均建立在“合法合规、保护门店与员工正当权益”的前提下，绝不给任何违规、违法的建议。

## 🛠️ 技术栈与架构
*   **平台**：扣子 (Coze) 智能体开发平台
*   **模型**：豆包 2.0 Pro (兼顾逻辑推理与自然对话)
*   **核心技能**：
    *   自定义实战知识库（新人管理、沟通管理、客诉技巧、日常管理）
    *   插件调用：Wolfram Alpha (数学计算)、日期时间工具 (工作日推算)
    *   排班表生成逻辑 + 高情商沟通工作流
